# Homebrew tap

Casks for the Patchbay menu bar apps.

```
brew tap noterikkirillov8/tap
brew trust noterikkirillov8/tap
brew install --cask <name>
```

- [Harbor](https://github.com/noterikkirillov8/harbor): Menu bar list of listening dev servers with one-click stop
- [Tally](https://github.com/noterikkirillov8/tally): Claude and Codex plan usage in the menu bar
- [Sweep](https://github.com/noterikkirillov8/sweep): Finds rebuildable dev junk and moves it to the Trash
- [Ledge](https://github.com/noterikkirillov8/ledge): Drag-and-drop shelf for files
- [Pinch](https://github.com/noterikkirillov8/pinch): Shrinks screenshots, photos and videos as you copy them
- [Switchboard](https://github.com/noterikkirillov8/switchboard): Menu bar board of running Claude Code and Codex sessions
- [Shutter](https://github.com/noterikkirillov8/shutter): Menu bar organiser with a roller-shutter bar and notch awareness
- [Vigil](https://github.com/noterikkirillov8/vigil): Keeps your Mac awake for a set time, lid closed, and always ends
- [Reel](https://github.com/noterikkirillov8/reel): Screen recorder that turns clicks into smooth zooms

The apps aren't notarised by Apple; the casks clear the quarantine flag on install.
